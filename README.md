# AK_SUSU — Система спасения для аэрокосмического аппарата

![версия](https://img.shields.io/badge/версия-2.0-blue)
![платформа](https://img.shields.io/badge/платформа-Arduino%20Nano%20%7C%20ESP32-green)
![лицензия](https://img.shields.io/badge/лицензия-MIT-lightgrey)

> Проект команды **AK_SUSU** для летней аэрокосмической школы (трек «Продвинутые»).  
> Разработана автономная система мягкой посадки аппарата массой до 500 г, сбрасываемого с высоты 50 м.  
> **Бонус:** сохранность сырого куриного яйца (коэффициент 1,5).

## 🚀 Основные возможности

- **Двухступенчатая парашютная система**  
  Тормозной парашют (Ø50 см) – стабилизация и снижение до 9 м/с.  
  Основной парашют (Ø153 см) – мягкая посадка со скоростью ≤2,7 м/с.

- **Автономное управление**  
  Микроконтроллер (Arduino Nano / ESP32) с датчиком высоты BMP280.  
  Решения принимаются на основе реальных данных – без радиоуправления и пиротехники.

- **Выдвижные амортизирующие опоры**  
  Срабатывают на высоте ≤25 м (строго по ТЗ), поглощают энергию удара, предотвращают опрокидывание.

- **Защита куриного яйца**  
  Амортизирующий контейнер + алгоритм мягкой посадки. Яйцо остаётся целым.

- **Полное логирование полёта**  
  Все события (раскрытие парашютов, выпуск опор, касание) записываются на SD‑карту с временной меткой.

- **Веб-сервис для анализа логов**  
  Загрузите CSV‑файл после испытаний – получите интерактивные графики высоты, скорости, ускорения, таблицу ключевых событий и 3D‑анимацию полёта.

## ✅ Соответствие техническому заданию

| Требование ТЗ | Реализация |
|---------------|-------------|
| Масса аппарата ≤500 г | Корпус из пенокартона + лёгкие компоненты → 480 г (с яйцом) |
| Место под регистратор организаторов (103×70×18 мм) | Предусмотрен отсек с жёсткой фиксацией, доступ без разборки |
| Высота сброса 50±5 м | Датчик BMP280 фиксирует стартовую высоту |
| Тормозной парашют вводится безусловно | Механическая «черепашка» (не требует электроники) |
| Скорость перед вводом основного ≤10 м/с | 9,5 м/с (расчёт + эксперимент) |
| Скорость приземления ≤3 м/с | 2,65 м/с (основной парашют 1,83 м²) |
| Посадочные опоры раскрываются на высоте ≤25 м | Логика: при снижении до 25 м серва выпускает опоры |
| Запрет пиротехники | Всё – сервоприводы, пружины, резинки |
| Регистрация параметров (высота, скорость, момент раскрытия) | Собственный логгер + регистратор организаторов |
| Предоставление методики обработки акселерометра | Python‑скрипт + веб‑сервис с интеграцией |

## 🧰 Аппаратная часть

| Компонент | Модель | Назначение |
|-----------|--------|-------------|
| Микроконтроллер | Arduino Nano / ESP32 | Обработка датчиков, управление сервами |
| Датчик высоты | BMP280 (I²C) | Измерение давления → высота, скорость снижения |
| Сервоприводы (2 шт.) | SG90 | Раскрытие основного парашюта и выпуск опор |
| SD‑карта | MicroSD (SPI) | Логирование телеметрии (CSV) |
| Аккумулятор | Li‑Po 2S 300 mAh | Автономное питание |
| Корпус | Пенокартон + PLA | Масса 50 г, отсек для регистратора 103×70×18 |
| Опоры | Карбоновые стержни + поролон | Амортизация, ход 35 мм |
| Тормозной парашют | Нейлон ripstop, Ø50 см | Стабилизация |
| Основной парашют | Нейлон ripstop, Ø153 см | Снижение до 2,65 м/с |

**Общая масса:**  
- Без яйца: 425 г  
- С яйцом: 485 г  
- Регистратор организаторов (~205 г) входит в эти цифры.

## 💾 Программное обеспечение

Код написан в среде Arduino IDE (C++), модульная структура:
AK_SUSU/
├── config.h # все настройки (пины, высоты, скорости)
├── telemetry.h # BMP280 – чтение высоты и скорости
├── servos.h # управление сервами (основной парашют, опоры)
├── logger.h # запись на SD‑карту (CSV)
├── debug.h # режим отладки (симуляция на земле)
└── AK_SUSU.ino # главный цикл: логика раскрытия


**Алгоритм:**

1. При включении – инициализация датчика, серв, SD‑карты.
2. Ожидание сброса – фиксация высоты старта.
3. Тормозной парашют вводится механически (черепашка) через 0,2 с.
4. Каждые 50 мс опрос BMP280 → текущая высота и скорость.
5. При высоте ≤25 м – выпуск опор (логгер фиксирует событие).
6. При высоте ≤20 м И скорость ≤8 м/с – раскрытие основного парашюта.
7. Посадка – запись в лог "LANDED".

**Режим отладки (DEBUG_MODE):**  
Позволяет тестировать последовательность раскрытия на земле без реального сброса.

## 🌐 Веб-сервис телеметрии

После полёта вы получаете CSV‑файл на SD‑карте.  
Откройте **index.html** (в составе репозитория) – и вы увидите:

- **Интерактивные графики** (высота, скорость, ускорение, давление)
- **Таблицу событий** с временем, высотой и типом события (DROGUE_DEPLOYED, LEGS_DEPLOYED, MAIN_DEPLOYED, LANDED)
- **2D‑ и 3D‑анимацию** аппарата, синхронизированную с логами
- **Автоматический расчёт** максимальной скорости, скорости посадки, длительности полёта

## 📐 Расчёт парашютной системы

> **Подробный вывод всех формул и численные расчёты находятся в файле [`Calculations and analysis/calculations/Parachute.md`](Calculations%20and%20analysis/calculations/Parachute.md).**

**Краткие результаты:**

| Параметр | Тормозной парашют | Основной парашют |
|----------|-------------------|------------------|
| Диаметр | 50 см | 153 см |
| Площадь | 0.20 м² | 1.83 м² |
| Скорость снижения | ~9.5 м/с | ~2.65 м/с |

Проверка с яйцом (0.56 кг) показала скорость приземления **2.65 м/с**, что удовлетворяет требованию ТЗ ≤3 м/с[reference:1]. Требование к скорости перед раскрытием основного парашюта (≤10 м/с) также выполнено: фактическое значение составляет 9.5 м/с[reference:2]. Расчёт требуемого хода амортизации опор показал необходимость минимум 3.5 см для защиты яйца[reference:3].

## 🛠 Как использовать

### 1. Сборка аппарата

- Распечатайте 3D‑модель корпуса (файлы в `cad/`) или вырежьте из пенокартона.
- Установите регистратор организаторов в отсек 103×70×18.
- Закрепите Arduino Nano, BMP280, SD‑модуль и сервы.
- Пришейте стропы к парашютам, уложите их в контейнеры.
- Подключите аккумулятор через выключатель.

### 2. Прошивка

1. Откройте `AK_SUSU.ino` в Arduino IDE.
2. Установите библиотеки: `Adafruit BMP280`, `SD`, `Servo`.
3. Выберите плату (Arduino Nano / ESP32).
4. Загрузите скетч.

### 3. Предварительные испытания (по п.10 ТЗ)

- Включите `#define DEBUG_MODE` в `config.h`.
- Нажмите кнопку на аппарате (или замкните контакт) – через 3 с «раскроется» тормозной, через 5 с – основной, через 7 с – опоры.
- Продемонстрируйте комиссии.

### 4. Реальные испытания

- Выключите `DEBUG_MODE`, залейте финальную прошивку.
- Вставьте SD‑карту.
- Подвесьте аппарат за ушки к БПЛА (расстояние между ушками ≤130 мм).
- Запустите полёт – после посадки извлеките SD‑карту.

### 5. Анализ данных

- Скопируйте `flight_XXX.csv` на компьютер.
- Откройте `web/index.html` в браузере, загрузите CSV.
- Изучите графики, таблицу событий, 3D‑анимацию.
