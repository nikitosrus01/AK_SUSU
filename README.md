# Петрушка - Система спасения куриного яйца

Проект разработан в рамках летней аэрокосмической школы (трек «Продвинутые») и посвящён созданию автономной системы спасения для малогабаритного аппарата массой до 500 г.

Основная задача — обеспечить **мягкую, стабильную и безопасную посадку** аппарата после сброса с высоты ~50 м с сохранением конструкции и полезной нагрузки (включая сырое яйцо в усложнённой версии задания).

---

## 🚀 Основные возможности проекта

- 🪂 **Двухступенчатая парашютная система**
  - тормозной парашют для стабилизации
  - основной парашют для мягкого снижения
- 🦿 **Автоматические посадочные опоры**
  - раскрытие на высоте ≤ 25 м
  - амортизация удара при посадке
- 🧠 **Автономная электроника**
  - работа без радиоуправления
  - использование датчиков высоты и ускорения
- 📊 **Веб-сервис анализа логов**
  - загрузка данных с бортового регистратора
  - визуализация высоты, скорости и событий
- 🧮 **Математические расчёты**
  - моделирование скорости снижения
  - расчёт параметров парашютов
  - анализ перегрузок при посадке
- 🥚 **Защита полезной нагрузки**
  - система амортизации для сохранения яйца

---

## 🧩 Архитектура системы

Проект состоит из нескольких ключевых подсистем:

### 1. Парашютная система
- последовательное раскрытие:
  1. тормозной парашют
  2. отделение тормозного
  3. раскрытие основного
- расчёт задержки для снижения скорости < 10 м/с перед вторым этапом

### 2. Посадочные опоры
- механическое или электромеханическое раскрытие
- срабатывание по высоте
- демпфирование удара

### 3. Электроника
- микроконтроллер
- датчики:
  - высотомер
  - акселерометр
- запись данных на карту памяти
- (опционально) передача телеметрии в реальном времени

### 4. Аналитическая платформа
- веб-интерфейс для анализа полёта
- обработка логов:
  - высота vs время
  - ускорение vs время
  - определение событий:
    - раскрытие парашютов
    - отделение ступеней
    - раскрытие опор
    - момент посадки

## 📐 Расчёты и моделирование

В проекте реализованы:

- расчёт площади купола парашюта
- оценка коэффициента сопротивления
- моделирование:
  - скорости снижения
  - времени падения
  - перегрузок при касании
- определение высоты раскрытия систем

Это позволяет ещё на этапе проектирования убедиться, что:
- скорость посадки ≤ 3 м/с  
- система успевает стабилизироваться  
- нагрузки безопасны для конструкции и полезной нагрузки

## 📦 Ограничения проекта (по ТЗ)

- масса ≤ **500 г**
- отсутствие:
  - пиротехники ❌
  - высокого давления (> 2 атм) ❌
- обязательное место под регистратор:
  - 103.4 × 70 × 18 мм
  - ~205 г
- полностью автономная работа

---

## 🧪 Испытания

### Условия:
- высота сброса: ~50 м
- способ: БПЛА или аэростат
- погода: без осадков, ветер ≤ 5 м/с

### Критерии успешности:
- скорость посадки ≤ 3 м/с
- вертикальная посадка на опоры
- отсутствие опрокидывания
- сохранность конструкции
- (дополнительно) целое яйцо 🥚
